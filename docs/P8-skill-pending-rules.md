## 1. 共通需要确认的字段

对没有明确规定的条件/智慧技能，请给出：

1. 每场最多成功发动几次。
2. 每场最多判定几次，失败是否允许下一checkpoint重试。
3. 效果持续几个checkpoint，或持续到哪个阶段结束。
4. 冷却是否存在，间隔几个checkpoint。
5. 同技能再次触发时刷新时长、替换、取强或叠加。

已确认的等级锚点和智慧Difficulty不用重新提供；R1.2六项条件不用重填。C07已经有技能库YAML明确的一场一次、持续一个checkpoint。
