## 已确认规则

- 数据源为 `P8_赛马系统完整策划/赛马娘马名与五维评分汇总.md` 总表116项；109项中文名有效、7项缺名先排除。游戏库只保存中文名，不保存英文别名。
- `/买马` 等概率抽取109个模板，允许同模板重复抽取；同玩家在厩重名时使用中文序号，如“特别周·二号”，保留既有唯一名称约束。
- 每项初始属性独立取整数：下限 `ceil(评分×15×0.8)`，上限 `floor(评分×15×1.2)`，上下限均包含。例如评分8对应96～144。取消原G0总和550～700及单项80～160限制；初始属性与养成上限1000兼容。成长等级概率、性别规则、售价1000币及容量检查沿用原实现。
- 推荐距离在表中的短距/英里/中距/长距候选项中等概率抽取，推荐跑法独立等概率抽取。泥地不参与距离抽取；表列泥地的马保存推荐场地泥地，其余保存草地。
- 马库推荐供购买回复、马厩及详情展示使用；它不覆盖P8相性等级或直接改变比赛倍率，当前赛程本体保持原规则。

## 持久化与兼容

`horse_catalog_v1.json` 为部署随源码携带的数据文件，运行时不解析docs、不访问外部服务。模板ID、中文原名、原评分、倍率、浮动范围、抽到的赛程/跑法/场地随五维写入既有 `birth_traits_json`；购买事件记录模板ID，规则版本为 `horse_catalog_v1`。固定seed可重建，函数支持注入RNG。

不新增schema或migration，不回填/重抽旧马、不改变已出生或待出生幼驹，不重置训练、余额或账本。改名、训练、交易后原始模板快照仍保留。

缺中文名的模板ID：087、088、092、095、097、098、099；获得正式中文名后才加入抽取池。
