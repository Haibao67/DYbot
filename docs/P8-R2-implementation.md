- G0购买与旧马首次 `/马`、`/报名`、`/繁育`补齐六槽；最高相性并列以马ID及初始化版本确定性选择，技能不重复，保留既有FINALIZED技能和父母/幼驹快照。初始随机等级复用技能库V1的Lv1～5权重30/27/22/14/7，不建立第二份规则。
- `application/daily_race_service.py`：代码配置 `DailyRaceTemplate`、`DailyRaceScheduler`、`RaceStateReconciler`、`RaceExecutionService`、启动校验。每次确保今天和明天，按时间追赶，不依赖某分钟精准触发。Core每60秒运行，Worker停止不阻止比赛计算；平台消息仍由原Worker发送。
- 固定澄露杯：北京时间12:00开放、19:45截止、20:00开赛，2000米、中距、草地·良、晴。2名真人起赛，每人1匹、最多10匹，2～7名补至8匹；不足2名取消全额退款。报名50币，冠亚季200/100/50币，NPC不领奖金；截止前玩家取消返90%。
- NPC优先补缺失跑法，再确定性选择未用模板；五维端点包含的均匀整数，六技能不重复，等级按35/30/25/10权重抽Lv1～4。同赛事/槽位/模板版本重建不变。
- 名单补齐后冻结相性、五维、成长、技能定义/等级、版本、日期、天气、起始格位与种子。正式运行只读该快照。快照存在不重新补NPC、不重写；版本不完整保持LOCKED并写审计。
- RUNNING无结果用原快照/种子重试；有结果不重新模拟，可恢复奖励结算。结果、结构化事件、逐马奖励、账本、战绩和最终状态在事务中一致提交。错误按运行时、NPC、快照、模拟、结算阶段记录，单场失败不影响其余赛事。
- `/赛程`、`/比赛详情`、`/报名`、`/取消报名`、`/观赛`、`/赛果`、`/战绩`、帮助、`/今日`和已报名/未报名待办接入。玩家指令继续原生引用该条消息。

## 配置与运维

```dotenv
DZMM_RACE_AUTO_ENABLED=true
DZMM_RACE_TIMEZONE=Asia/Shanghai
```

Core Settings默认启用自动日赛；`Store`测试/嵌入接口默认不启用，需显式传 `race_auto_enabled=True`。关闭自动调度不删除任何赛事或资产。启动会补建并追赶逾期赛事；修复配置后下一轮自动重试。可从审计 `RUNTIME_VALIDATION_FAILED` / `NPC_GENERATION_FAILED` / `SNAPSHOT_GENERATION_FAILED` / `RACE_SIMULATION_FAILED` / `SETTLEMENT_FAILED`定位错误。

仅支持本轮固定模板及版本组合。短距/长距/泥地赛事、随机天气、HARD/ELITE、赛季、成就、世界动态和赛事技能奖励继续关闭；普通赛事全群公告是策划可选项，本轮未启用自动广播，玩家通过赛程/今日查询。
