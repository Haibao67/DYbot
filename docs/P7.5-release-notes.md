## 实现

- 玩家命令统一回复出口：保守以UTF-16单位控制1000字上限，最多10次主动换行；优先合并而不分页，不截断内容。
- 只有超限时缓存完整分页正文，玩家使用 `/回复页 页码` 查询；按玩家和房间隔离，24小时有效，下一次超长回复覆盖旧分页。每页引用该条查询消息。
- 牧场A：同类动物两行、保留心形与0级无心、库存摘要；倒数第二行按动物组汇总增产概率。
- 农场A：按作物与成熟状态聚合，分批成熟显示最近时间；农田详情保留每块状态。
- 动植物及产品Emoji；马匹属性使用中文名称和前置Emoji；命令名与参数不插入Emoji。
- 加工厂主面板压缩、配方单项详情、库存明细、模块帮助；帮助显示P7.5。
- 行情短条目双项一行；交易费用与余额合并，普通回复不再显示累计奖池。
- 首次提示合并一行；没有空间时不记录“已展示”；签到仅附待办摘要，完整待办另查。
- 公告经过同一紧凑格式处理，超限拒绝发布并提示缩短；不在正式平台自动连发长公告。
- 精饲料固定产量×1.15改为增产概率20%；与每只闪光5%同池累加。每100%必定基数+1，余数再判定；同周期不重复叠加精料20%。
- 新批次保存精料概率与稀有规则版本；旧已完成产品保留旧数量/倍率快照，不改写历史资产。空收取不触发，已收批次不重算。
