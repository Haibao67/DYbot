# P8-R1.1 implementation

2026-09-28，本地代码，未部署。R1相性版本保持不变；新引擎版本 `race_engine_v1.1`。

## Implemented

- `domain/race_rules_r11.py`：位置百分位、四跑法目标中心、PositionControl/Adjustment、四档PaceState、三lane拥堵与安全检查、换道概率、完整超车概率及技能加成上限、全部16智慧技能Difficulty。
- `domain/race_engine_r11.py`：九checkpoint分段距离模拟；各马独立加速时间/完赛时间；低体力、毅力保护、分机制相性倍率、每段三角速度随机与起步三角加速随机。
- 每checkpoint先计算基础Position/Pace一次，再调用技能，随后应用速度/加速与随机；不因速度技能再次扫描Pace。路线读取同一快照，避免逐马更新污染。
- 最少拥堵的安全候选lane（同分选内侧）作为首版确定性路线选择；一次checkpoint最多一次主动换道。不为外道额外添加速度收益。
- soft/hard block、换道事件、超车成功/部分/失败及对应0.5%/1%/1.5%最大体力成本；失败下段速度-2%。成功离散超车交换相对完成时间，失败保留原相对时间差，部分成功不越过目标。
- checkpoint中将独立到达时间差按领马速度换算成纵向米差，供下一checkpoint路由使用；这是离散引擎的时间/距离表示，不是连续横向坐标模型。
- 1900m后进入终点对抗，最后100m应用DuelScore；完赛按0.001秒→DuelScore→horse_id；0.25m内照片判定事件。
- 所有新事件含race_id/checkpoint及可复现event_id。观赛继续只读保存的结果，显示换道、避堵和照片判定；赛果显示完赛时间。
- 冻结快照追加天气/版本、创建时间及完整技能定义；运行前比较当前定义，防止同ID换效果后重算历史赛果。
- `domain/race_setup_r1.py`：北京时间12:00/19:45/20:00固定赛制工厂、六NORMAL模板、Lv1～4、优先无放回与四跑法覆盖。模板不完整技能不会被静默替换。
- 赛事服务支持R1分机制相性、每人报名上限、取消后重新报名重新扣费、真实玩家不足时全额取消退款；主动取消账本分为报名费返还与取消手续费，整场取消使用 `race_full_refund`。

## Activation boundary

提供 `race_rules_r11.build_engine(registry)`、`race_setup_r1.daily_definition(now,seed)` 和 `R1NpcFactory(registry)`，用于显式装配既有CompetitionService/Core到期链路。没有自动创建正式赛事或修改线上开关。

R1.1所列核心公式已落地。完整P8-R1开放仍需要：30个技能可执行配置、G0/旧马六技能初始化、每日赛事自动创建装配与测试验收。仍有以下技能触发数值未被R1/R1.1/技能库定义：

- C03安全领先距离、C04与领马距离阈值。
- W01轻微/严重起步失误判定与惩罚。
- W05“前方密度过高”的阈值。
- W08/W09体力偏低/充足、是否必须冲刺的判定。
- W10同距离体力安全线，以及速度代价-1%～-3%的对应规则。

未编造起步失误状态来激活C01/W01。起步加速随机已实现，起步失误技能单独门控。R1属性0～1000是模拟输入约束，不截断或重置玩家数据库中的现有培养值。
