# 瑞禾开放问题

## P0：平台原生引用验收

- **已确认协议：** 用户提供的 `DZMM_ACCOUNT_AND_MESSAGE_INTEGRATION_GUIDE.md` 指定普通账号 Socket `message:send` 的 `message.content.reference` 结构为 `{id, sentBy, content:{type:"text", text}}`。Bot API `/api/bot/send-message` 只定义普通文本，不用于带引用上下文的任务。
- **剩余验收：** 尚未在授权测试群确认客户端 UI 显示、无效原消息的响应以及交错玩家场景。代码已按指南构造引用，不猜测字段名。

## P2：每日天气概率（阻塞天气启用）

- **已知规则：** 丰收祭目标概率为 10%；晴天、雨季、旱季、闷热、微风的生产效果已给定。
- **待提供：** 其余五种天气的概率分配。用户明确表示后续提供，因此当前 P2 版本不生成/持久化每日天气，面板显示天气功能暂未启用；生产默认不应用天气加成。

## P2：生产数量取整（已决定）

- **决定：** 统一使用 Decimal `ROUND_HALF_UP` 对每一生产批次取整，沿用项目现有货币格式化的半入规则；纯规则测试覆盖边界。当前基础每批 1 件，日后如改变批量数仍走同一函数。
