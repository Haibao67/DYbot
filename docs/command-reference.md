## 行情与交易

动态价格按基准价中心的截断正态分布生成：标准差16.67%，价格范围基准50%～150%；相邻窗口使用相关随机样本保持平滑。仍每30分钟全服刷新一次，固定价加工品不受影响。实际交易金额保留两位小数。

## 等级效率与统一收获

牧场和农场等级工时倍率均为 `1−0.05×(L−1)`，Lv1为1.00，Lv9为0.60。牧场最终工时为基础工时×等级工时倍率×亲密度工时倍率；亲密度工时倍率保留 `1/(1+0.01×亲密度等级)`，两个倍率相乘。农场新播种应用等级倍率；升级时未成熟作物保留已完成进度并缩短剩余时间，已成熟产品不变。已有种植快照通过level-v2规则标记避免重复应用倍率。

`/收取` 与 `/收获` 均一次领取牧场产物和农场成熟作物；旧 `/牧场 收获` 同样使用统一入口。重复消息沿用原入站幂等，所有领取在同一事务，不包括加工厂 `/取货`。

## 群红包

- `/发红包 <金额> [份数] [时长分钟]`，份数默认10份，持续时长默认2分钟；每次领取后重置无人领取时间。
- `/抢红包` | `/抢`，仅当前群已注册且正常玩家可领取，发起人不能抢，每人每包一次，每群同时一个未领完红包。
- `/结束红包`，仅管理员可在本群结束当前红包，并退回未领取余额。
- 每份按分随机抽取，限制为原始平均金额50%～150%；按剩余份数限制抽样范围，保证最终总额精确。金额太小而无法按分满足范围时提示增加金额或减少份数。
- 发出或最近一次成功领取后，2分钟无成功领取即到期，余款退给发起人；失败抢包、重复抢包不会续期。Worker定期维护、Core后台和新入站命令均可幂等结算到期退款；实际退款落账随后台轮询，到期后不能继续领取。
- 扣款、领取、退款均记入现有currency_ledger，红包与领取记录持久化、领取有唯一键；SQLite沿用立即事务，PostgreSQL沿用world及红包行锁。无新增正式群广播。

## P8-R2 每日赛马（本地，未部署）

北京时间每日12:00开放、19:45截止、20:00自动开赛；报名50币，每人1匹青年或成年马。

年龄规则：出生不足3小时为幼驹，不能喂马或参赛；3～6小时为青年，可喂马和参赛；满6小时成年，才可繁育。新购买马保持青年阶段，购买3小时后成年；已有马保留born_at，按新阈值判断阶段。

日赛最多20匹；赛程只展示日期短标识，例如 `/比赛详情 2026-09-29`、`/报名 2026-09-29 马名 先行`。原完整赛事ID仍兼容；不指定日期时沿用当前赛事规则。尚未锁定的已有日赛随调度同步容量20，已冻结赛事及历史快照保持原样。

也可使用 `/报名 澄露杯 马名 跑法`、`/比赛详情 澄露杯`。报名选择当前可报名的澄露杯；详情选择最早未结束赛事，没有未结束赛事时显示最近已结束赛事。

管理员可使用 `/管理员开赛 名称 距离米 赛程类型 报名分钟 [草地|泥地]` 创建自定义赛事并立即开放报名，例如 `/管理员开赛 春风杯 2000 中距 10 草地`。名称最多40字（不含空格），赛程类型为短距/英里/中距/长距，报名1～1440分钟，场地默认草地。报名结束自动开跑，费用50币、奖金200/100/50、最多20匹、至少2名真实玩家，其他规则沿用澄露杯；人数不足取消退费。同名活跃赛事有多场时需指定赛事ID。支持 `/报名 春风杯 马名 跑法`、`/比赛详情 春风杯`。

| 命令 | 用途 |
| --- | --- |
| `/赛程` | 查看今天及明天的赛事编号与状态。 |
| `/比赛详情 <赛事>` | 查看条件、报名费及奖金。 |
| `/报名 <赛事> <马名或编号前缀> <跑法>` | 跑法：逃、先行、差、追；自动补定未初始化的旧马技能。 |
| `/取消报名 <赛事> <马名或编号前缀>` | 截止前取消返还90%。 |
| `/观赛 <赛事>` | 查看已完成比赛的关键事件。 |
| `/赛果 <赛事>` | 查看排名与完赛时间。 |
| `/战绩 <马名或编号前缀>` | 查看历史战绩和赛后分析。 |

`/今日`显示赛事状态与时间，`/待办`提示已报名开赛时间或未报名的截止提醒；自动赛事由Core推进，无需管理员逐场操作。

可以省略赛事编号：`/报名 马名 跑法`选择当前报名中的赛事；`/比赛详情`、`/观赛`、`/赛果`自动选择最近已开放的赛事。显式编号写法保留。

### 管理员自定义与强制开赛（最新语法）

- `/开赛 名称 距离米 报名分钟 [参赛上限] [草地|泥地]`，例如 `/开赛 春风杯 2000 10 20 草地`。
- 名称最多40字、不含空格；报名1～1440分钟；距离大于1000、100整数倍；上限8～20匹，默认20；场地默认草地。赛程类型按距离自动确定。
- `/强制开赛 赛事`，例如 `/强制开赛 春风杯`；省略赛事默认澄露杯。至少两名真实玩家，提前关闭报名后立即模拟、结算；重复执行不重复派奖。
- 两命令均仅管理员可用，普通玩家不可绕过服务权限。旧 `/管理员开赛` 作为名称别名兼容，参数使用新语法。
- 现阶段继承50币报名费和前三200/100/50币奖金；未来可在赛事定义的prizes/reward_items扩展，物品奖励未开放。


### 管理员强制成年

`/成马 <马名>`（繁体 `/成馬`）：仅管理员可用，作用于管理员本人拥有的有效马匹，名称有歧义时可用马匹ID。仅调整年龄至成年，保留属性、培养次数、繁育冷却等状态；比赛锁定或拍卖托管中的马不可修改。重复执行不继续改变年龄。`/开赛` 与 `/强制开赛` 均在路由和服务层校验管理员权限。


### 拍卖玩家资产（最新入口）

- `/拍卖 鸡蛋 10 100`：托管10个鸡蛋，整批起拍100币。
- `/拍卖 鸡蛋 100`：数量省略时拍卖1个，起拍100币。
- `/拍卖 马 春风 100`：拍卖自己拥有的春风；也可 `/拍卖 春风 100`。同名物品优先，需要指定马时使用“马”。
- `/拍卖 物品 燕麦种子 5 100`：明确按库存物品处理。原料、作物、种子、饲料、马粮、加工品、道具及闪光动物均走物品托管；未有中文映射的未来物品可使用库存item_code。
- 原 `/寄拍 马 马名 起拍价`、`/寄拍 道具 物品 数量 起拍价` 保留。`/拍卖`不再接受无实物的任意文字标题。
- 数量1～100000、起拍价沿用正整数币；费用、冷却、竞价、成交交付、流拍退还规则不变；马匹沿用赛马/怀孕/拍卖锁定和满马厩托管保护。


### 自动赛马播报

成功开赛后自动发送开赛提示、关键事件摘要和前三结果。新自定义赛发到创建群，每日赛发到有效游戏群，旧未记录来源的自定义赛也使用有效游戏群。播报走Worker队列，按顺序发送，不重新模拟比赛。提示使用赛事名称：`/观赛 春风杯 | /赛果 春风杯 | /战绩 马名`。已结束自定义赛按名称取最新赛果；旧完整ID查询保留。


### 检查点定时播报

每个检查点播报阶段、距离、前三位置与剩余体力，当前9个检查点后发送最终赛果。相邻播报至少间隔10秒（从Worker发送确认计时；网络/队列可能延长）。全部目标群最终播报确认完成前，`/赛果`、`/观赛`提示播报中；发送失败或不确定不会提前解锁。计算与奖金结算仍在开赛时一次完成，不代表真实时间逐步模拟。


### 管理员强制接生

`/强制接生`（繁体 `/強制接生`）：仅管理员可用，立即接生管理员本人全部待产幼驹，不需要等待预产时间。必须已有成功繁育记录，不创建免费繁育、不重抽属性和继承、不再扣费、不清除父母繁育次数或冷却；新马仍为幼驹。复用正常接生事务和确定性子代ID，重复执行不会重复出生。


### 繁育顺序自动识别

`/繁育 马名1 马名2`：只需一公一母，填写顺序不限。内部自动识别父母，血统、遗传和母马怀孕记录始终按真实性别保存。成年、冷却、繁育次数、近亲限制、材料及马厩空位要求保留。


### 完整排名播报

所有检查点及最终播报显示完整排名，短条目以 `||` 并排利用行宽，达到1000字或10次换行硬限制后自动续发，续段保留赛事阶段标题。每个检查点全部段落发完再等10秒发送下一个检查点；同检查点续发沿用平台节流。`/赛果`显示所有名次并自动分多条Reply，不需要手动翻页。


### 比赛NPC来源

新版本赛事NPC与 `/买马` 共用名马库和初始五维随机规则（评分×15、上下20%）。中文名、成长、性别及推荐距离/场地/跑法保存在赛事快照，相性和六技能使用购买马初始化规则；NPC采用抽到的推荐跑法。NPC仍只补足最低参赛数，不消耗玩家货币，不进入玩家马厩，不获得玩家奖金。旧版赛事保留旧快照及版本规则。


## 旧赛事统一 NPC 规则（本地，未部署）

新赛事与尚未结算的旧赛事均采用 `/买马` 的中文马匹库、五维评分×15±20%、成长、相性及六技能生成规则。旧报名赛事锁定时采用新规则；已有锁定快照且未产生赛果的赛事，在开赛事务中替换 NPC 快照，保留玩家马匹、NPC 位置和赛事种子，并持久化新规则版本。重复开赛不重复生成。已产生赛果的赛事保留原历史结果及奖励，避免重复结算。无需 schema 迁移。仅通过语法及模块导入检查，未运行功能测试、未部署。
