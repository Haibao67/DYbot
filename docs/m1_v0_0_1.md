# M1 v0.0.1 更新说明

## 1. 版本与范围

- 版本号：M1 v0.0.1
- 更新日期：2026-09-25
- 适用环境：本地 `E:\game\bot` 与云服务器 `119.28.232.86`（`/srv/dzmm/app`）
- 数据库：SQLite（本地测试）/ PostgreSQL（服务器正式库）

本次更新把原来只有收发队列和基础账户的旧版 Core，升级为「M0 账户体系 + M1 牧场经济」的完整版本，并引入 Alembic 数据库迁移，替换了旧版的 `create_all` 建表方式。

## 2. 本次更新概述

1. **代码分层重构**：把原来集中在 `store.py` 里的表定义和游戏逻辑拆分为 `application`、`domain`、`persistence`、`presentation` 四层。
2. **引入 Alembic 迁移**：新增 `0001_foundation`、`0002_ranch` 两个迁移版本，替换旧的 `create_all`。
3. **新增 M0 账户功能**：全局唯一账户、不可变货币/库存账本、每日救济、冻结/解冻、管理补偿与审计。
4. **新增 M1 牧场经济**：购买/喂食/收获/出售/升级，确定性生产、动态市场价、5% 交易税奖池与总榜。
5. **新增灰度开关**：`DZMM_GAME_STAGE`（m0 / ranch / full）与 `DZMM_GAME_WHITELIST`。
6. **新增依赖**：`alembic==1.20.0`、`Mako==1.4.3`、`MarkupSafe==3.0.3`。

## 3. 架构与代码重构

### 3.1 目录结构

| 目录 | 职责 |
| --- | --- |
| `dzmm_bot/application/` | 命令路由（`command_router.py`）、业务服务（`services.py`）、生产复核（`verification.py`） |
| `dzmm_bot/domain/` | 纯规则层：经济参数、税收、容量、市场价、生产间隔等（`economy.py`） |
| `dzmm_bot/persistence/` | 表结构（`schema.py`、`transport.py`）与迁移（`migrate.py`、`migrations/`） |
| `dzmm_bot/presentation/` | 玩家可见文案与渲染（`messages.py`） |

### 3.2 主要拆分

- 旧 `store.py` 内的表定义拆到 `persistence/transport.py`（原有收发表）和 `persistence/schema.py`（新增游戏表）。
- 游戏指令分发移到 `application/command_router.py`，业务规则集中在 `domain/economy.py`。
- `store.py` 保留事务性的收发队列、任务租约与业务调度，启动时自动执行 `migrate()`。

## 4. 新增功能：M0 账户体系

### 4.1 玩家指令

| 指令 | 说明 |
| --- | --- |
| `/加入` | 首次加入，仅在已启用的群中生效，获得初始 100 币并建立牧场 |
| `/我的` | 查看昵称、余额、加入时间、账户状态 |
| `/救济` | 余额低于 100 时补足到 100，香港时间每天限领一次 |
| `/帮助` | 按当前开放阶段显示帮助文本 |
| `/排行 总榜 [页码]` | 全局余额总榜 |

### 4.2 账户与账本

- 全局唯一账户：一个平台账号在所有已启用房间共享同一账户。
- 货币/库存账本与余额投影在同一事务提交，禁止更新或删除。
- 系统奖池使用空玩家 ID，通过部分唯一索引防止空值绕过去重。
- 管理补偿带工单号，同一玩家相同工单重放不会重复变更。

### 4.3 管理能力

- 冻结/解冻玩家，冻结后不能变更资产。
- 正负补偿（`amount` 非零整数、`reason`、`ticket` 必填）。
- 账本查询、牧场查询、生产复核。

## 5. 新增功能：M1 牧场经济

### 5.1 牧场指令

| 指令 | 说明 |
| --- | --- |
| `/牧场 查看 [页码]` | 查看等级、容量、动物、库存、当前单价 |
| `/牧场 购买 鸡\|羊\|牛\|饲料 [数量]` | 购买动物或饲料 |
| `/牧场 喂食 <动物编号>` | 消耗饲料，重置该动物 48 小时生产期 |
| `/牧场 收获` | 结算到期产出并入库存 |
| `/牧场 出售 鸡蛋\|羊毛\|牛奶\|全部 [数量]` | 按当前市场价出售 |
| `/牧场 升级` | 提升牧场等级与容量 |

### 5.2 经济参数

| 参数 | 值 |
| --- | --- |
| 初始余额 | 100 币 |
| 救济下限 | 100 币 |
| 交易税率 | 5%（`tax_bps=500`） |
| 饲料价格 | 2 币 |
| 生产期 | 48 小时 |
| 最高等级 | 9 级 |
| 基础容量 | 3 格，每级 +2 格 |
| 升级费用 | 200 × 1.5^(当前等级−1) |
| 等级生产加速 | 每级 +10% |
| 市场价波动幅度 | ±15%（按香港时间正弦波动） |

### 5.3 动物与产品

| 动物 | 占容量 | 购买价 | 单次喂食 | 生产间隔（小时） | 产品 |
| --- | --- | --- | --- | --- | --- |
| 鸡 | 1 | 50 | 1 饲料 | 2–4 | 鸡蛋 |
| 羊 | 2 | 120 | 2 饲料 | 10–14 | 羊毛 |
| 牛 | 3 | 300 | 3 饲料 | 6–10 | 牛奶 |

| 产品 | 基准价 |
| --- | --- |
| 鸡蛋 | 5 |
| 羊毛 | 20 |
| 牛奶 | 15 |

### 5.4 生产与交易规则

- 生产间隔由 HMAC 派生种子确定性计算，可从持久化快照复核已产出的产品。
- 交易税 5% 进入系统奖池，累计为「奖池累计税额」。
- 出售逐品类计税，出售「全部」时按当前库存依次出售。
- 停产动物仍占容量，当前规则不允许再次喂食或复活。

| 阶段 | 开放内容 |
| --- | --- |
| `m0` | 只开放账户：`/加入`、`/我的`、`/救济`、`/帮助` |

## 9. 规则口径（上线前需明确）

- 新玩家首次加入必须来自已启用的群；随后任意已启用群或已登记私聊可访问同一账户。
- 生产期已结束的动物不能再次喂食；提前喂食会结算旧产出后重置 48 小时，并舍弃旧的剩余间隔。
- 停产动物仍占容量，本次未提供复活动物或出售动物功能。
- 升级不会修改已有动物的时间与等级快照，新购、重新喂食时采用当时等级。
- 基础榜单为当前余额总榜；日赛/周赛积分榜留给后续赛事阶段。

## 12. 已知限制与后续

- 仅支持单 Core + 单 Worker，跨进程任务领取锁尚未实现，不要多开副本。
- 图片上传、分享、引用、撤回、自动发现新私聊、Web 管理后台/noVNC 暂未实现。
- 生产级数据库版本迁移已引入 Alembic，但跨平台依赖与容量需在扩大玩家规模前进一步验证。
- 正式上线建议按 `m0` → `ranch` → `full` 分阶段灰度，并完成 M0 24 小时观察、M1 白名单测试群与 72 小时观察后再签署生产验收。
