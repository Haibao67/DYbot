# P8-R1.2 实现记录

2026-09-28，本地代码，未部署。

## 本轮实现

- `race_rules_r12.py` 集中保存六项条件、起步概率/等级相性修正、轻重失误及距离惩罚；独立版本 `race_engine_v1.2`，R1.1 保持原语义。
- C03：领跑第一、领先第二至少 2.5m。C04：先行非第一、排名百分位不超过 40%、距第一不超过 4m。
- W08：末弯体力 (10%,28%]、基础 Pace 为 SLOW/NORMAL。W09：末弯体力至少 35%、落后本跑法理想区。
- W10：中盘处于理想排名区且体力低于安全线；按尚未跑完的 checkpoint 距离投影基础消耗，包含当前待跑段，排除 Pace、技能、随机、超车附加项。安全线为投影×1.10，封顶最大体力。两次独立判断，单 checkpoint 成功只执行一次；等级消耗减免与速度代价统一线性插值。
- W01：单次 StartRoll 分类，只修正轻微失误；按 NORMAL 难度智慧判定，修正延迟和加速损失，不改变原始失误分类。
- 起步顺序：StartRoll→W01→确定最终惩罚→C01→首段运动；轻微前50m/严重前80m使用降低后的加速度，剩余距离恢复；延迟只计一次。严重失误禁用 C01。
- 七条版本化技能（六项补充技能及 C01）采用 `R12_` ID/code，不覆盖数据库旧技能定义。通过 `r12_registry()` 显式装配，并由 `build_engine(registry)` 创建 R1.2 引擎。未自动授予技能或启动赛事。
- CompetitionService 支持 R1.2 的完整相性与技能快照；起步事件包含概率、随机抽样、原始分类、最终惩罚，观赛显示对应中文说明。
