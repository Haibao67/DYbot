# 32. ProjectedRemainingCost

定义：


# 33. ProjectedRemainingCost 不包含

为了保证安全线稳定：

```text

技能效果

```

```text

```

导致触发逻辑不稳定。

# 47. 起步失误基础公式

定义：

```text
PowerNorm
=
Power /1000

WisdomNorm
=
Wisdom /1000
```

起步失误率：

```text
P_StartError
=
0.20
-
0.08 × PowerNorm
-
0.08 × WisdomNorm
-
StartAffinityBonus
```

最后：

```text
P_StartError
=
clamp(
    P_StartError,
    0.03,
    0.18
)
```

# 48. StartAffinityBonus

使用：

```text
本场所选择跑法的相性
```

| 跑法相性 | StartAffinityBonus |
|---|---:|
| S | +0.030 |
| A | +0.015 |
| B | 0 |
| C | -0.015 |
| D | -0.030 |

由于公式是：

```text
- StartAffinityBonus
```

所以：

```text
S

```


# 50. 轻微与严重失误

发生失误以后：

```text
SeverityThreshold
=
P_StartError ×0.25
```

如果：

```text
StartRoll
<
SeverityThreshold
```

结果：

```text

```

否则：

```text
MINOR_ERROR
```

因此：

> 发生失误时，约 25% 为严重失误，约 75% 为轻微失误。

# 58. Start Engine 正式执行顺序

起步阶段：

```text
① 读取 Power

② 读取 Wisdom

③ 读取本场跑法相性

④ 计算 P_StartError

⑤ 生成 StartRoll

⑥ 得到：

⑦ 如果 MINOR

```

# 62. 最终冻结汇总

| 项目 | 正式定义 |
|---|---|
| C03 安全领先距离 | `gap_to_second >= 2.5m` |
| C04 差距不大 | `gap_to_leader <= 4.0m` |
| C04 前集团 | `PositionPercentile <= 0.40` |
| W08 体力偏低 | `10% < StaminaRatio <= 28%` |
| W08 尚无需冲刺 | `PaceState ∈ {SLOW, NORMAL}` |
| W09 体力充足 | `StaminaRatio >= 35%` |
| W09 排名落后 | `PositionPercentile > TargetMax` |
| W10 安全线 | `ProjectedRemainingCost ×1.10` |
| W10 无需抢位 | 当前位于跑法目标区间 |
| W10 速度代价 | Lv1 -3% → Lv10 -1% |
| W01 起步失误 | Power + Wisdom + 跑法相性 |
| MINOR_ERROR | +0.12s；前50m加速度×0.92 |
| SEVERE_ERROR | +0.28s；前80m加速度×0.82 |
| W01 作用范围 | 只处理 `MINOR_ERROR` |
