# 14. ChosenStrategyEV 加成落点

原 R1.3：

```text
ChosenStrategyEV
+= skill_bonus
```

存在循环歧义：

```text
必须先选策略
才能知道给谁加成
```

因此正式改为：

> **先计算三种策略的基础 EV，找到基础 EV 最高的候选策略，然后把技能加成加到该策略，再做最终选择。**

---

# 15. BaseBestStrategy

首先计算：

```text
InsideEV
HoldEV
OutsideEV
```

然后：

```text
BaseBestStrategy
=
argmax(
    InsideEV,
    HoldEV,
    OutsideEV
)
```

---

# 16. SkillDecisionBonus

```text

```

# 17. 最终策略选择

```text
ChosenStrategy

```

# 18. 技能加成不固定给某一种路线

W14：

```text
不会固定强化内切
```

也不会：

```text
固定强化外绕
```

也不会：

```text
固定强化保持
```

它强化的是：

> **当前 RaceContext 中基础判断已经最优的策略。**

设计含义：

```text
高智慧成功发动
→ 更坚定、更准确地执行当前最优决策
```

---

# 20. 平局优先级设计原因

保持：

```text
风险最低
额外体力成本为0
```

内切：

```text
有少量切线成本
```

外绕：

```text
距离与体力成本最高
```

因此同等收益时：

```text
优先选择风险更低的方案
```

# 23. W14 完整执行顺序

```text
① 进入 FINAL_CORNER

② 检查 W14 前置条件

③ WisdomTriggerResolver 判定成功

④ 构建合法候选策略：
   内切
   保持
   外绕

⑤ 计算：
   InsideEV
   HoldEV
   OutsideEV

⑥ 根据基础 EV
   找到 BaseBestStrategy

⑦ 若基础 EV 近似平局：
   保持 > 内切 > 外绕

⑧ 对 BaseBestStrategy
   加 SkillDecisionBonus

⑨ 再次比较 AdjustedEV

⑩ 得到 ChosenStrategy

⑪ 执行路线动作

⑫ 按策略扣除：
   ActualExtraStaminaCost
```

---

# 24. 实际体力消费时点

W14 的路线额外体力：

```text
在策略成功进入执行阶段时扣除
```

即：

```text
ChosenStrategy
确认
↓
路线动作执行
↓
扣 ActualExtraStaminaCost
```

如果：

```text
候选策略因 lane 安全条件变化而无法执行
```

则：

```text
退回保持策略
```

且：

```text
不扣失败候选策略的额外体力
```

---

# 25. 回退规则

如果最终选：

```text
内切
```

但实际执行前：

```text
内侧 lane 不再满足安全条件
```

则：

```text
Fallback
=
保持
```

外绕同理。

回退：

```text
不重新进行 W14 智慧判定
```

也：

```text
不重新寻找第二优策略
```

统一：

```text
直接保持当前 lane
```

保证执行简单、确定。
