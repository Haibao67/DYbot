> **版本：P8-Skill-V1**  
> **用途：马匹养成 2.0 / 繁育 / 赛马 Race Engine / P7A 拍卖展示**  
> **设计原则：参考《赛马娘 Pretty Derby》中“直线、弯道、回复、跑法、距离、场地、位置与条件发动”等技能设计思路，但本文件的技能名称、等级曲线、触发逻辑与效果均为 DYbot 原创设计。**

# 0. 技能系统总规则

每匹马拥有：

```text
6 个技能槽
```

技能等级：

```text
Lv.1 ~ Lv.10
```

技能类型：

```text
PASSIVE
被动技能

CONDITIONAL
条件触发技能

WISDOM_TRIGGER
智慧触发技能
```

技能来源：

```text
父母继承
随机补位
赛事奖励道具（预留）
```

繁育继承：

```text
父亲随机继承 3 个
+
母亲随机继承 3 个
```

同名技能：

```text
取双方更高等级
+1级
最高 Lv10
```

出现空位：

```text
从 inheritance_random_pool 抽取
Lv1~Lv5 技能补满
```

# 1. 技能效果术语

为了避免未来 SkillDefinition 中出现含糊描述，统一使用以下术语。

| 术语 | Race Engine 含义 |
|---|---|
| 速度发挥 | 修改 `target_speed / effective_speed` |
| 加速度 | 修改达到目标速度的速度 |
| 体力消耗 | 修改当前阶段 stamina cost |
| 体力恢复 | 按最大体力百分比恢复 |
| 超车能力 | 修改 overtake 判定 |
| 位置控制 | 修改向目标跑法位置移动的稳定性 |
| 堵塞惩罚 | 修改 `blocked` 状态造成的损失 |
| 路线判断 | 修改换道、避堵、择线成功率 |
| 毅力发挥 | 修改低体力与终点对抗中的 grit 效果 |
| 智慧判定 | 修改 `WisdomTriggerResolver` 的发动概率 |

# 6. 智慧触发技能 WISDOM_TRIGGER

这类技能先满足客观条件，再经过：

```text
WisdomTriggerResolver
```

成功后发动。

建议基础概率由：

```text
马匹智慧
+
技能等级
+
当前压力

跑法相性
```

# 14. 技能强度控制原则

由于一匹马拥有 6 个技能，单技能数值必须克制。

原则：

```text
被动：
通常 1%~8%

条件技能：
通常 3%~16%
但持续时间短

智慧技能：
更多改变决策、路线、消耗
避免纯数值爆炸
```

禁止：

```text
单一 Lv10 技能
直接提供 30% 全程速度
```

否则技能会覆盖五维和相性。

# 15. 五维与技能关系

技能不能替代五维。

例如：

```text
【末脚爆发 Lv10】
```

只能提高：

```text
速度发挥
```

真正的速度上限仍来自：

```text
horse.speed
```

同理：

```text
【外道强攻】
```

提高超车成功率，

但力量低的马依然不应该拥有和高力量马相同的突破能力。

推荐：

```text
最终技能收益
=
技能效果
× 对应属性发挥系数
```

但该系数应由 Race Engine 统一处理，不写进每个技能。

# 20. 设计参考说明

本技能库借鉴的是《赛马娘 Pretty Derby》常见的**技能设计维度**，例如：

- 直线 / 弯道触发；
- 速度与加速度提升；
- 体力回复或疲劳降低；
- 跑法限定；
- 距离限定；
- 场地与赛道条件；
- 位置与超车条件；
- 最终直线或终盘发动；
- 路线与位置控制。

为了适应 DYbot：

- 所有技能名重新设计；
- 不复制原游戏技能数值；
- 技能等级统一改为 Lv1~10；
- 增加智慧触发类型；
- 增加文字事件输出；
- 强调与五维、相性、跑法、堵塞、超车系统的接口；
- 与 P8 的 6 技能继承体系直接兼容。

# 21. 最终目标

技能系统上线后，玩家不应该只说：

```text
“这匹马有6个高等级技能。”
```

而应该出现：

```text
“它虽然速度不是最高，
但是中距S + 差S，
还有Lv8弯道突进和Lv7追击时机，
特别适合中距差马。”

“这匹追马耐力一般，
但有末段韧性和不屈余火，
最后直线经常还能继续追。”

“这匹马智慧特别高，
外道预判和临机换道的发动很稳定，
很少被堵死。”
```

这才说明：

> **技能、五维、相性与跑法真正共同构成了马匹的个体差异。**
