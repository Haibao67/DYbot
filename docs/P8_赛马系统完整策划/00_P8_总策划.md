# 🏇 DYbot · P8「马匹养成 2.0 与正式赛马系统」总策划

> **阶段：P8**  
> **主题：五维能力 × 相性 × 跑法 × 技能 × 血统 × 赛事模拟**  
> **目标：让马匹属性、相性与技能在文字赛马中真正“看得见、读得懂、能复盘”。**

---

# 0. 一句话定位

P8 不再使用“总属性 + 随机数 = 名次”的简单结算，而是建立适合文字 Bot 的离散阶段赛马系统：

```text
马匹五维
× 距离相性
× 场地相性
× 跑法相性
× 当前体力
× 位置与路线
× 技能触发
× 小幅随机
= 各比赛阶段的真实表现
```

玩家要能从比赛文字中理解：为什么某匹马起步更好、为什么中盘掉速、为什么被堵、为什么弯道能连续超车、为什么最后 100 米还能继续咬住对手。

# 2. 五维在比赛中的职责

| 属性 | 核心机制 |
|---|---|
| ⚡速度 | 巡航速度、最高速度、最终直线速度 |
| 🫀耐力 | 体力池、长距离续航、失速阈值 |
| 💪力量 | 起步、加速、弯道再加速、超车、复杂场地 |
| 🧠智慧 | 配速、路线、避堵、跑法执行、智慧技能触发 |
| 🔥毅力 | 低体力维持、最后冲刺、并排竞争、终点对抗 |

设计原则：五维必须“机制化”，不能只作为最终总分的不同权重。

# 5. 技能系统总规则

每匹马最多 6 个技能，技能等级 1~10。

类型：

```text
PASSIVE         被动技能
CONDITIONAL     条件触发技能
WISDOM_TRIGGER  智慧触发技能
```

来源：

```text
父母继承
赛事奖励道具（P8 先保留接口）
随机补位
```

繁育时：

```text
父亲 6 个技能中随机 3 个
+
母亲 6 个技能中随机 3 个
```

同名技能：

```text
取更高等级 +1
最高 Lv10
```

同名融合导致的空位：

```text
从 inheritance_random_pool 补位
随机技能等级 Lv1~Lv5
```

高级技能的长期来源因此自然形成：

```text
随机补位：最高 Lv5
血统融合：可逐代提升到 Lv10
赛事奖励：未来提供另一条成长线
```

| 中盘巡航 | 耐力、智慧、距离相性 |

| 最终弯道 | 速度、力量、体力、技能 |
| 最后直线 | 速度、毅力、剩余体力 |
| 终点对抗 | 毅力、速度、剩余体力 |

# 7. 四跑法

## 🟥 逃

尽快取得领先，减少堵塞，但前段体力消耗最大。核心属性：速度、智慧、耐力。

## 🟧 先行

稳定处于前集团，整体风险最低。核心属性：速度、力量、智慧。

## 🟦 差

前半程保存体力，中后程寻找空档超车。核心属性：力量、智慧、速度。

## 🟪 追

前半程主动留后，最后阶段连续追击。核心属性：速度、毅力、力量，风险最高。

# 8. 场地与赛道状态

场地：草地 / 泥地。

赛道状态：

```text
良
稍重
重
不良
```

- 良：标准；
- 稍重：力量价值略升；
- 重：力量与耐力更重要；
- 不良：力量、耐力和场地相性显著影响表现。

# 14. 老马迁移

P8 不重置老马。

相性初始可以为：

```text
U = 未补定
```

通过：

```text
horse_id + affinity_generation_version
```

做一次确定性补定，之后永久保存。

技能状态：

```text
UNINITIALIZED
FINALIZED
```

历史马的技能补定留独立接口，不在数据库迁移中直接随机。

# 20. P8 成功标准

玩家讨论应从：

```text
“谁总属性高？”
```

变成：

```text
“这匹马中距S、差S，特别适合2000m。”
“速度很高，但耐力不够，长距跑不出来。”
“智慧高，冷静换道发动特别稳定。”
“父母都有弯道加速，后代已经叠到Lv9。”
“总属性一般，但场地和跑法非常契合。”
```

最终闭环：

```text
培养
↓
繁育
↓
获得不同相性与技能后代
↓
报名适合赛事
↓
文字直播看到属性发挥
↓
赛后发现短板
↓
继续培养
↓
形成赛事荣誉与高价值血统
```
