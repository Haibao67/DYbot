# P8-7 · 赛程、报名、观赛与赛果

> **目标：把底层 Race Engine 包装成玩家真正能参与的赛事系统。**

---

# 1. 核心命令

```text
/赛程
/比赛详情 [赛事]
/报名 [赛事] [马] [跑法]
/取消报名 [赛事] [马]
/观赛 [赛事]
/赛果 [赛事]
```

所有玩家主动命令使用平台原生引用回复。

# 7. 报名验证

顺序：

```text
赛事存在
↓
处于 REGISTRATION
↓
未超过报名截止
↓
马匹属于玩家
↓
马匹成年且未退役
↓
未被拍卖/繁育/其他赛事锁定
↓
未重复报名
↓
报名费足够
↓
跑法合法
↓
创建 RaceEntry
```

所有扣费与 Entry 创建处于同一事务。

---

# 8. 低相性报名

不禁止玩家使用低相性距离、场地或跑法。

例如：

```text
⚠️ 星河的【逃】相性为 D。
本次仍按你的选择报名。

🏇 已报名【澄露杯】
跑法：逃
```

因为 Bot 不适合大量二次确认，第一版可以“执行 + 明确提示”。

---

# 9. 取消报名

允许在：

```text
registration_close_at
```

之前取消。

报名费规则配置化。

第一版建议：

```text
截止前取消 → 全额返还
```

返还同样写入 ledger。

---

# 10. 报名锁

报名阶段可以使用轻量 reservation。

正式截止后：

```text
RaceEntry → LOCKED
```

马匹进入：

```text
race_locked
```

禁止：

```text
喂马
繁育
退役
拍卖
修改技能
其他会改变比赛快照的数据
```

---

# 11. 比赛快照

报名截止时保存：

```text
RaceHorseSnapshot
```

包括：

```text
五维
成长（用于展示）
三类相性
六技能与等级
状态
跑法
```

正式开赛只读取快照。

避免：

```text
报名后临时喂马
→ 比赛能力被改写
```

---

# 12. 开赛

Worker 扫描：

```text
status = LOCKED
AND starts_at <= now
```

执行：

```text
start_race()
```

要求幂等。

---

# 13. `/观赛`

比赛结束后：

```text
/观赛 1024
```

从已持久化 `RaceEvent` / `RaceResultSnapshot` 读取。

禁止每次观赛重新跑模拟。

---

# 14. 直播输出策略

不要把所有底层 Checkpoint 都输出。

只展示：

```text
阶段开始
明显排名变化
重要超车
堵塞/避堵
重要技能
体力危险
最终冲刺
终点对抗
```

使一场比赛控制在可读长度。

# 16. 平局处理

底层可以保留更高精度：

```text
finish_score
finish_time_internal
```

展示可以使用：

```text
鼻差
头差
颈差
半马身
1马身
```

若内部仍完全相同，再使用固定 RNG tie-break，并记录原因。

# 20. 异常处理

赛事人数不足：

```text
P8-10 NPC 补位
```

Race Engine 失败：

```text
赛事不得发奖
保持可恢复状态
管理员可重试同 seed
```

# 22. 验收标准

玩家能完整完成：

```text
看赛程
→ 看赛事详情
→ 选择马
→ 选择跑法
→ 报名
→ 等待
→ 观赛
→ 看赛果
```

且比赛期间马匹数据不会被其他系统修改。
