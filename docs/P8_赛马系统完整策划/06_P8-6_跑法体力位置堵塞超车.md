# P8-6 · 跑法、体力、位置、堵塞与超车

> **目标：让逃、先行、差、追真正成为四种不同比赛策略，并让力量与智慧在文字比赛中可感知。**

---

# 1. 目标位置

```text
逃：前 0~15%
先行：前 15~40%
差：中后 40~75%
追：后 25%
```

只是目标区间，不是强制名次。

---

# 2. 跑法相性影响

```text
目标位置执行稳定性
体力效率
智慧决策稳定性
超车时机
```

低相性不会禁止该跑法，只会增加执行代价和不稳定性。

---

# 3. 体力结构

前段：

```text
逃 > 先行 > 差 > 追
```

通常逃马更早消耗体力。

但后程差/追需要更多：

```text
加速
换道
超车
```

因此总消耗不简单按跑法排序。

---

# 4. Pace State

```text
SLOW
NORMAL
FAST
OVERPACE
```

智慧影响马匹是否选择适合自身耐力、距离和跑法的节奏。

---

# 5. 堵塞

当：

```text
前方近距离存在马匹
+
所在 lane 可用空间不足
```

产生：

```text
blocked = true
```

堵塞影响：

```text
速度发挥
加速度
超车机会
```

---

# 6. 智慧避堵

高智慧更容易：

```text
提前换道
主动稍微减速保存体力
寻找外侧路线
```

低智慧更容易：

```text
继续跟随
错过空档
无效加速
```

---

# 7. 超车判定

核心：

```text
力量
当前速度
智慧
跑法
双方位置
赛道空间
技能
```

结果：

```text
SUCCESS
PARTIAL
BLOCKED
FAILED
```

成功：位置前移。

PARTIAL：缩小差距但未完全超过。

失败：可能消耗体力但位置不变。

---

# 8. 弯道价值

弯道强化：

```text
力量
智慧
路线
```

力量不足：弯道出口再加速慢。

智慧不足：更容易选到拥堵路线。

---

# 9. 最后直线

体力充分：

```text
速度完整发挥
```

低体力：

```text
速度上限降低
```

毅力降低低体力状态的衰减。

---

# 10. 并排竞争

最后阶段差距极小：

```text
head_to_head = true
```

主要比较：

```text
毅力
速度
剩余体力
相关技能
```

---

# 11. 场地状态

良：标准。

稍重：力量价值轻微提高。

重：力量、耐力更加重要。

不良：场地相性、力量、耐力明显影响表现。

---

# 12. 文字事件

堵塞：

```text
⚠️ 星河被前方马群挡住了路线！
```

避堵：

```text
🧠 星河提前向外侧移动，成功避开拥堵。
```

超车：

```text
💪 星河从外侧猛然提速！
排名：6 → 4
```

终点：

```text
🔥 两匹马已经完全并排！
星河仍然没有放弃！
```

# 14. 验收标准

玩家需要明显看出：

- 逃主动抢前；
- 追主动留后；
- 智慧影响堵塞和节奏；
- 力量影响加速和超车；
- 毅力影响最后竞争；
- 换跑法后同一匹马的比赛过程明显不同。
