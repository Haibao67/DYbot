# 12. 相性遗传规则

每一个相性槽独立遗传。


# 14. 相性变异

基础遗传完成后，再进行一次 `affinity_mutation`。

| 变化 | 概率 |
|---|---:|
| +2级 | 0.5% |
| +1级 | 4.5% |
| 不变 | 90% |
| -1级 | 4.5% |
| -2级 | 0.5% |

等级顺序：

```text

```

封顶 S，最低 D。

# 15. 后代不做 B 保底

G0 每类至少一个 B+，但繁育后代不保底。

原因：繁育必须真正体现血统质量。如果父母两边某一类相性都很差，后代也应该存在继续变差的风险。

# 31. 低体力衰减

```text
StaminaRatio = CurrentStamina / MaxStamina
```

如果 `StaminaRatio >= 0.20`，无疲劳惩罚。

低于 20%：

```text
FatiguePenalty = 0.35 × (1 - StaminaRatio / 0.20)
```

---

# 32. 毅力补偿

```text
GritNorm = grit / 1000
```

```text
GritGuard = 0.10 + 0.40 × GritNorm^0.8
```

```text
FinalFatiguePenalty
=
FatiguePenalty × (1 - GritGuard)
```

```text
StaminaFactor = 1 - FinalFatiguePenalty
```

耐力决定什么时候开始疲劳，毅力决定疲劳以后掉多少速度。

# 35. Segment 时间

若 `CurrentSpeed < TargetSpeed`：

```text
d_acc = (TargetSpeed² - CurrentSpeed²) / (2 × Acceleration)
```

若 `d_acc < SegmentDistance`，则先加速，再以目标速度完成剩余距离；否则整段都处于加速。

因此力量会真实影响达到最高速度所需时间。

# 36. 比赛随机波动

每个 segment：

```text
SpeedRandom = Triangular(-2.5%, 0, +2.5%)
```

```text
AccelerationRandom = Triangular(-4%, 0, +4%)
```

所有随机必须使用 `race_seed`。

同一个 `RaceSnapshot + race_seed` 必须得到完全相同赛果。

# 38. Soft Block

同 lane 前方马匹距离 `<= 4.0m` 时进入 soft block。

影响：超车判断、路线判断、部分加速度发挥。

---

# 39. Hard Block

如果同 lane 前方距离 `<= 2.2m`，且自己的目标速度至少高于前马 `0.25m/s`，进入 hard block。

此时：

```text
TargetSpeed
=
min(
  原TargetSpeed,
  前马CurrentSpeed ×0.995
)
```

直到换道、完成超车或前马拉开。

---

# 42. 超车尝试条件

满足：

```text
前方距离 <= 4m
```

```text
自己的 TargetSpeed > 前车 TargetSpeed + 0.15m/s
```

# 43. 超车成功率

```text
P_overtake
=
0.40
+ 0.18 × PowerDiff
+ 0.10 × WisdomDiff
+ 0.20 × SpeedAdvantage
+ RunningStyleBonus
+ SkillBonus
+ LaneBonus
- TrackPenalty
```

其中：

```text
PowerDiff = (self.power - target.power) / 1000
WisdomDiff = (self.wisdom - target.wisdom) / 1000
```

最终限制：`8% ~ 92%`。

---

# 44. 超车结果

## SUCCESS

位置交换，额外消耗 `MaxStamina ×0.5%`。

## PARTIAL

若 RNG 落在成功阈值后额外 10% 范围，则差距明显缩短但未完成超越，额外消耗 `MaxStamina ×1.0%`。

## FAILED

位置不变，额外消耗 `MaxStamina ×1.5%`，下一小段速度 `-2%`。

---

# 45. 终点对抗

1900m 时，如果两匹马距离 `<=1.5m`，进入 `HEAD_TO_HEAD`。

```text
DuelScore
=
0.45 × SpeedNorm
+ 0.35 × GritNorm
+ 0.20 × sqrt(StaminaRatio)
+ SkillModifier
+ Random
```

Random：`±2%`。

最后 100m：

```text
HeadToHeadSpeedFactor = 0.98 + 0.04 × DuelScore
```

---

# 46. 照片判定

终点距离差 `<=0.25m` 时：

```text
📸 照片判定！
```

使用精确 `finish_time` 判断，精确到 `0.001秒`。若仍完全一致，则依次使用 `DuelScore → horse_id` 保证确定性。

# 50. 智慧技能发动公式

智慧技能先满足 Trigger Condition，再计算：

```text
P_trigger
=
0.10
+ 0.55 × WisdomNorm^0.85
+ 0.02 × (SkillLevel - 1)
+ RunningStyleAffinityBonus
- TriggerDifficulty
```

限制：`15% ~ 92%`。

跑法相性修正：

```text
S +5%
A +3%
B  0%
C -3%
D -6%
```

TriggerDifficulty：

```text
EASY   0%
NORMAL 5%
HARD   10%
```

技能等级主要影响技能强度和少量发动修正，智慧主要影响是否能抓住发动机会。

# 110. P8-R1 成功标准

P8-R1 做对以后，玩家应该能够明确感受到：

```text
“这匹马速度高，所以直线真的快。”

“耐力不够，最后开始掉速了。”

“力量高，弯道超车特别明显。”

“智慧高的马很少自己跑崩。”

“毅力高的马最后100米真的难甩开。”

“这匹马中距S，所以2000米特别适合。”

“它虽然总属性更高，但差只有D，跑差反而很难受。”

“这个技能不是单纯加分，而是真的在弯道发动了。”
```

如果玩家最后只看到：

```text
属性总和高的马总是赢
```

则说明 P8-R1 设计失败。

最终目标是：

> **马匹的五维、相性、跑法、技能和血统共同塑造不同比赛风格，而不是最终被压缩成一个隐藏总战力。**
