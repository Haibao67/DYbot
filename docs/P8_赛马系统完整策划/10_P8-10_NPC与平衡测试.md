# P8-10 · NPC 补位、固定 RNG 与整体平衡测试

> **目标：让低活跃服务器也能稳定开赛，并建立可重复、可量化的赛马平衡验证流程。**

---

# 1. NPC 定位

NPC 不用于作弊，也不应拥有隐藏加成。

用途：

```text
补足参赛数量
提供基准对手
验证不同流派
让低在线群也能稳定开赛
```

---

# 2. NPC Archetype

建议至少：

```text
短距高速型
长距耐力型
力量差马
智慧逃马
毅力追马
泥地力量型
均衡先行型
```

---

# 3. 参考模板原则

外部五维资料只作为：

```text
类型特征参考
```

例如：

```text
速度极高 + 耐力偏低
```

转为“短距高速模板”。

不要直接复制某个角色完整固定数值作为系统标准。

# 5. NPC 难度

```text
EASY
NORMAL
HARD
ELITE
```

普通赛事：

```text
NORMAL 为主
```

高奖金/特殊赛事：

```text
HARD / ELITE
```

NPC 难度必须通过模板公开控制，不允许临场偷偷按玩家强度动态作弊。

---

# 6. NPC 补位

赛事：

```text
min_horses = 6
max_horses = 10
```

截止时只有 4 匹玩家马：

```text
自动补 NPC 到目标数量
```

配置：

```text
npc_fill_enabled
npc_fill_min
npc_fill_target
npc_difficulty_pool
```

---

# 7. 固定 RNG

所有比赛、继承、NPC 创建都必须支持：

```text
injectable RNG
fixed seed
fixed clock
```

测试禁止：

```text
sleep
不可复现随机
```

---

# 8. Monte Carlo 平衡测试

离线批量模拟：

```text
1000场
10000场
```

统计：

```text
胜率
前三率
平均排名
平均剩余体力
超车成功率
堵塞率
技能发动率
各跑法表现
各距离表现
各相性表现
```

---

# 9. 五维验证

必须能回答：

```text
速度高是否在短距更有价值？
耐力高是否在长距更稳定？
力量高是否更容易完成加速和超车？
智慧高是否减少无效消耗与堵塞？
毅力高是否提升最后阶段竞争？
```

如果某项属性长期几乎不改变比赛结果，就代表设计失败。

---

# 10. 相性验证

目标：

```text
S 比 B 有稳定优势
但不是绝对碾压
```

同时：

```text
总属性略低但相性优秀
```

应该存在合理胜过“总属性高但相性差”的情况。

---

# 11. 跑法验证

必须保证：

```text
逃
先行
差
追
```

都有适合的距离、属性结构和赛事环境。

禁止某一种跑法长期统治所有距离。

---

# 12. 技能验证

重点：

```text
Lv10 不应压过全部基础属性
Lv1~5 技能仍然有意义
智慧技能成功率随智慧合理变化
同名融合值得长期繁育
随机补位最高 Lv5 不会过强
```

---

# 13. 平衡指标

长期监控：

```text
不同 archetype 胜率
不同跑法胜率
相性等级胜率
技能等级收益
不同代数马匹胜率
NPC vs 玩家胜率
```

出现某跑法、技能或单属性长期异常占优时，再调整配置，而不是修改历史马匹。

---

# 14. 状态系统测试

如果使用：

```text
绝佳 +3%
良好 +1%
普通 0
低迷 -3%
```

必须验证状态只制造小波动，不能盖过属性和相性。

---

# 15. 压力测试

至少模拟：

```text
10场同时结算
100场连续结算
500场历史赛果读取
多群同时观赛
排行榜聚合
```

重点检查：

```text
CPU
DB 写入
RaceEvent 体量
观赛读取
排行榜查询
Worker 重入
```

---

# 16. 全系统锁回归

必须验证：

```text
auction_locked
race_locked
breeding_locked
```

互斥正确。

同一匹马不能：

```text
正在拍卖
同时参赛
同时繁育
```

# 18. 回归范围

P8-10 最终必须回归：

```text
P6 马厩
P7 农场
P7A 拍卖
P8 全阶段
```

尤其验证：

- 原有 `/喂马` 不受影响；
- 繁育次数与父母关系正确；
- 农场马粮正常；
- 拍卖锁正确；
- 赛事锁正确；
- 战绩与拍卖快照一致。

```text

seed_range

各跑法胜率
各距离胜率
各 archetype 胜率
技能触发统计

```

方便未来调参对比。

---

# 20. 验收标准

- 玩家不足仍可开赛；
- 所有比赛可复现；
- 随机不盖过培养；
- 五维全部具有可测价值；
- 相性明显但不绝对；
- 四跑法都有生存空间；
- 技能没有压垮基础属性；
- 全流程回归通过。
