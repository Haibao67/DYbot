# 3. 相性遗传原则

当前阶段重点是接口和长期方向，不把概率彻底写死在代码。

核心规则：

```text
父母某项相性都高
→ 后代该项高相性概率明显增加
```

例如：

```text
父：中距 S
母：中距 A
```

后代应该更容易获得：

```text
中距 A / S
```

而不是简单 50% 复制父或母。
