# 1. PositionAdjustment

首先将当前名次转换为位置百分位。

设：

```text
rank = 当前名次
N = 当前参赛马数量
```

第一名：

```text
PositionPercentile = 0
```

最后一名：

```text
PositionPercentile = 1
```

公式：

```text
PositionPercentile
=
(rank - 1) / (N - 1)
```

---

# 2. 四种跑法目标位置

| 跑法 | 目标区间 | TargetCenter |
|---|---|---:|
| 逃 | 0%～15% | 0.075 |
| 先行 | 15%～40% | 0.275 |
| 差 | 40%～70% | 0.550 |
| 追 | 70%～100% | 0.850 |

计算：

```text
PositionError
=
PositionPercentile - TargetCenter
```

含义：

```text
PositionError > 0
```

说明：

```text
当前位置比理想位置更靠后
→ 马匹会尝试提高配速
```

如果：

```text
PositionError < 0
```

说明：

```text
当前位置比理想位置更靠前
→ 马匹会尝试略微保存体力
```

# 3. PositionControl

定义：

```text
WisdomNorm
=
wisdom / 1000
```

位置控制能力：

```text
PositionControl
=
(0.55 + 0.45 × WisdomNorm)
× RunningStylePositionMultiplier
```

其中跑法相性倍率：

| 相性 | RunningStylePositionMultiplier |
|---|---:|
| S | 1.10 |
| A | 1.05 |
| B | 1.00 |
| C | 0.94 |
| D | 0.85 |

# 4. PositionAdjustment 最终公式

```text
RawPositionAdjustment
=
0.06
× PositionError
× PositionControl
```

然后：

```text
PositionAdjustment
=
clamp(
    RawPositionAdjustment,
    -0.020,
    +0.025
)
```

也就是：

```text
最多主动降速：
-2.0%

最多主动追位：
+2.5%
```




```text

=
```

```text

=
```

```text

```

这匹马因此会主动提高约：


# 6. PaceState 配速状态

配速状态不能直接使用最终速度。

否则：

```text
速度技能
随机波动
```

可能错误触发：

```text
OVERPACE
```

因此首先计算：

```text
NeutralTargetSpeed
```

NeutralTargetSpeed 包含：

```text
BaseSpeed
距离相性
场地相性
跑法阶段倍率
赛道状态
体力状态
```

但不包含：

```text
PositionAdjustment
技能
随机波动
```

---

# 7. TacticalTargetSpeed

```text
TacticalTargetSpeed
=
NeutralTargetSpeed
× (1 + PositionAdjustment)
```

定义：

```text
PaceRatio
=
TacticalTargetSpeed
/
NeutralTargetSpeed
```

由于：

```text
TacticalTargetSpeed
=
NeutralTargetSpeed × (1 + PositionAdjustment)
```

所以本质上：

```text
PaceRatio
=
1 + PositionAdjustment
```

---

# 8. PaceState 正式判定

| PaceState | 条件 |
|---|---|
| SLOW | `PaceRatio < 0.985` |
| NORMAL | `0.985 <= PaceRatio <= 1.010` |
| FAST | `1.010 < PaceRatio <= 1.020` |
| OVERPACE | `PaceRatio > 1.020` |

等价于：

```text
PositionAdjustment < -1.5%
→ SLOW

-1.5% ～ +1.0%
→ NORMAL

+1.0% ～ +2.0%
→ FAST

> +2.0%
→ OVERPACE
```

---

# 9. PaceState 体力倍率

| 状态 | 体力消耗倍率 |
|---|---:|
| SLOW | ×0.92 |
| NORMAL | ×1.00 |
| FAST | ×1.08 |
| OVERPACE | ×1.18 |

P8-R1：

> 每个 Checkpoint 都重新计算一次 PaceState。

首版不做 hysteresis。

# 10. CongestionPenalty

CongestionPenalty 用于：

```text
换道成功率
```

以及后续智慧路线判断。

它表示：

> 目标 lane 的局部拥挤程度。

# 11. 拥挤统计

定义：

```text
N_close
```

为：

```text
目标 lane 中
与自己纵向距离绝对值 <= 4.0m
的其他马数量
```

定义：

```text
N_medium
```

为：

```text
目标 lane 中
4.0m < 距离绝对值 <= 8.0m
的其他马数量
```

---

# 12. CongestionPenalty 正式公式

```text
CongestionPenalty
=
min(
    0.20,
    0.05 × N_close
    +
    0.02 × N_medium
)
```

最大：

```text
20%
```

# 38. TriggerDifficulty 与技能等级

禁止：

```text

→ TriggerDifficulty 降低
```


```text

```

# 39. Position / Pace / Skill 执行顺序

每个 Checkpoint 固定：

```text
① 计算基础目标位置

② 根据当前排名
计算 PositionPercentile

③ 计算 PositionError

④ 计算 PositionControl

⑤ 计算 PositionAdjustment

⑥ 得到 TacticalTargetSpeed

⑦ 根据 TacticalTargetSpeed
判定基础 PaceState

⑧ 检查智慧类节奏技能

例如：
节奏校准
抑制过速
中盘节能

⑨ 技能修改 TacticalTargetSpeed
或 Pace 状态

⑩ 应用其他速度/加速度 Modifier

⑪ 加入 RandomFactor

⑫ 得到最终 TargetSpeed
```

该执行顺序：

> **P8-R1 固定，不允许在不同 Resolver 中各自重新计算。**

# 40. Pace 技能禁止递归触发

例如：

```text
抑制过速
```

触发条件：

```text
PaceState = OVERPACE
```

发动后可能：

```text

```

但：

```text
本 Checkpoint 不重新执行智慧技能触发扫描
```

即：

```text
PaceState
每个 Checkpoint
只完成一次基础判定
```

禁止出现：

```text
Pace
→ Skill
→ Pace
→ Skill
→ Pace
```

无限或重复循环。
