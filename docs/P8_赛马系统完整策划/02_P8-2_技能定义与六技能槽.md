# P8-2 · 技能定义、六技能槽与 Registry

> **目标：建立长期可扩展的技能底层，使未来增加大量技能时无需修改 Horse 主表和 Race Engine 主流程。**

---

# 1. 基础规则

```text
每匹马最多 6 个技能
技能等级 Lv1~Lv10
同一匹马不能有两个同名技能
```

---

# 2. 技能类型

```text
PASSIVE
CONDITIONAL
WISDOM_TRIGGER
```

分别对应被动、条件触发、智慧触发。

# 9. 等级曲线

每个技能自定义 `level_scaling`。

例如：

```text
Lv1 +3%
Lv5 +7%
Lv10 +12%
```

不能统一 `Lv10 = Lv1×10`。

# 14. 赛事奖励接口

```text
SkillGrantService.grant_skill(
  horse_id,
  skill_id,
  level,
  source
)
```

返回：

```text
GRANTED
UPGRADED
SLOT_FULL
REPLACE_REQUIRED
MAX_LEVEL
```

P8 暂不实现赛事奖励道具交互，但接口必须存在。

---

# 15. 老马技能状态

```text
UNINITIALIZED
FINALIZED
```

历史马默认 `UNINITIALIZED`，新出生马完成技能继承后为 `FINALIZED`。

# 17. 验收标准

- 0~6 技能稳定保存；
- 等级与来源可追溯；
- Registry 可扩展；
- Race Engine 不依赖技能名；
- 赛事奖励接口已留；
- 槽位与等级约束完整。
