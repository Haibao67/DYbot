# 1. 共通阶段边界

为解决多个技能共用的“前半程 / 后半程 / 中盘后半”等描述，正式冻结以下定义。

---

## 1.1 前半程

```text
ProgressRatio < 0.50
```

其中：

```text
ProgressRatio
=
CompletedDistance / RaceDistance
```

---

## 1.2 后半程

```text
ProgressRatio >= 0.50
```

---

## 1.3 跨越 50% 的 Segment

如果一个 Segment：

```text
start_ratio < 0.50
AND
end_ratio > 0.50
```

不拆分实际物理 Segment。

但技能效果按距离比例拆分：

```text
前半程效果
只作用于该 Segment 中
位于 50% 之前的距离比例

后半程效果
只作用于 50% 之后的距离比例
```

例如：

```text
Segment：
45% → 65%
```

总跨度：

```text
20%
```

其中：

```text
前半程：
45% → 50%
= 25% segment

后半程：
50% → 65%
= 75% segment
```

若技能为：

```text
前半程体力 -4%
```

则该 Segment 实际修正：

```text
-4% × 25%
=
-1%
```

# 5. 位置控制类效果统一接口

所有写着：

```text
位置控制 +X%
位置推进 +X%
路线效率 +X%
```

不得直接：

```text
最终速度 +X%
```

统一接入：

```text
PositionControl
```

基础：

```text
PositionControl
=
(0.55 + 0.45 × WisdomNorm)
× RunningStylePositionMultiplier
```

技能修正：

```text
EffectivePositionControl
=
PositionControl
× (1 + PositionControlSkillBonus)
```

所有同类技能合计：

```text
PositionControlSkillBonus
=
clamp(
    sum(skill_bonus),
    -0.20,
    +0.25
)
```

# 6. 路线决策基础模型

用于 W04 / W13 / W14 / W16 等路线型技能。

每个候选 lane 计算：

```text
LaneScore
=
DistanceScore
+
CongestionScore
+
OvertakeScore
+
SurfaceScore
+
StyleScore
```

最终选择：

```text
分数最高的合法 lane
```

---

# 7. DistanceScore

默认：

```text
内道 lane0 = +0.030
中道 lane1 = +0.015
外道 lane2 = 0
```

含义：

```text
内道距离更短
外道距离略长
```

---

# 8. CongestionScore

```text
CongestionScore
=
- CongestionPenalty
```

例如：

```text
CongestionPenalty = 0.12
```

则：

```text
CongestionScore = -0.12
```

---

# 9. OvertakeScore

若当前存在可超车目标：

```text
OvertakeScore
=
ExpectedOvertakeProbability × 0.08
```

否则：

```text
0
```

---

# 10. SurfaceScore

草地良场首版：

```text
所有 lane = 0
```

泥地未来由 W16 使用独立抓地系数。

---

# 11. StyleScore

| 跑法 | 内道 | 中道 | 外道 |
|---|---:|---:|---:|
| 逃 | +0.015 | 0 | -0.010 |
| 先行 | +0.010 | +0.005 | 0 |
| 差 | 0 | +0.005 | +0.010 |
| 追 | -0.005 | +0.005 | +0.015 |


```text
TargetAdjustment = -1.5%
```

然后：

```text
NewAdjustment
=
OldAdjustment
+
(TargetAdjustment - OldAdjustment)
× CorrectionRate
```

```text
最多2次成功/场
```

```text

```
