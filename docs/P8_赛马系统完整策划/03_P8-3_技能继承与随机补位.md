# P8-3 · 技能继承、同名融合与随机补位

> **目标：将技能正式纳入血统，让高等级技能能够通过多代繁育逐渐积累。**

---

# 1. 继承流程

```text
父亲 6 技能中无放回随机 3 个
+
母亲 6 技能中无放回随机 3 个
↓
合并同名技能
↓
空位随机补位
↓
最终固定 6 个技能
```

---

# 2. 无重复情况

```text
父：A4 B6 C3
母：D5 E2 F7
```

后代直接：

```text
A4 B6 C3 D5 E2 F7
```

---

# 3. 同名融合

```text
父：弯道加速 Lv6
母：弯道加速 Lv8
```

后代：

```text
max(6,8)+1 = Lv9
```

统一公式：

```text
child_level = min(max(parent_levels)+1, 10)
```

Lv10 封顶。

---

# 4. 空位

```text
父：A B C
母：A D E
```

A 融合后：

```text
A+ B C D E
```

只剩 5 个技能，因此产生 1 个随机补位槽。

多重重复同理：重复几组，就补几个随机技能。

---

# 5. 随机补位

随机池：

```text
inheritance_random_pool
```

每个空位：

```text
抽取一个幼驹尚未拥有的技能
```

技能等级：

```text
Lv1~Lv5
```

禁止随机出现 Lv6~Lv10。

随机等级概率配置：

```text
random_skill_level_weights
```

当前只固定“最高 Lv5”，具体权重后续可调。

---

# 6. 排除重复

```text
available_pool =
inheritance_random_pool
-
child_current_skill_ids
```

随机补位阶段不再允许抽中已有技能后继续融合，避免逻辑无限循环。

# 9. 技能继承快照

保存：

```text
SkillInheritanceSnapshot
```

至少包含：

```text
father_skill_snapshot
mother_skill_snapshot
father_selected_3
mother_selected_3
duplicate_groups
merged_levels
random_fill_skills
random_fill_levels
final_child_skills
algorithm_version
rng_seed_reference
created_at
```

---

# 10. 为什么必须快照

父母之后可能通过赛事奖励获得新技能或升级技能，但已经出生的幼驹不能重算。

继承只看出生时快照。

---

# 11. 算法版本

```text
skill_inheritance_algorithm_version = 1
```

未来改变继承规则时，新幼驹走 v2，历史幼驹永久保留旧结果。

---

# 12. 确定性 RNG

建议 seed 基于：

```text
birth_event_id
horse_id
algorithm_version
```

确保：

```text
事务失败重试
Worker 重复执行
/接生 重复请求
```

都不会生成不同技能。

---

# 13. 接生幂等

同一个 pregnancy / birth job：

```text
只能创建一匹幼驹
```

幼驹创建、技能继承、相性继承必须处于同一事务。

# 15. 长期育种意义

```text
优秀父母技能
↓
同名技能反复融合
↓
Lv6 / Lv7 / Lv8 / Lv9
↓
最终形成 Lv10 招牌血统
```

随机补位最多 Lv5，因此不会抢掉长期血统培养的价值。
