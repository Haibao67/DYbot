# P8-5 · 三类技能触发与 Effect 执行器

> **目标：让被动、条件触发、智慧触发统一接入 Race Engine。**

---

# 1. 被动技能 PASSIVE

流程：

```text
Race 初始化
→ 检查技能适用条件
→ 注册 Modifier
→ 全程或指定阶段持续生效
```

例如：

```text
【强健体魄】
体力消耗降低
```

---

# 2. 条件触发 CONDITIONAL

```text
Hook
→ TriggerEvaluator
→ 条件满足
→ EffectExecutor
```

例如：

```text
【末脚】
最后直线
且当前排名 >=4
→ 临时提高速度
```

---

# 3. 智慧触发 WISDOM_TRIGGER

```text
条件满足
→ WisdomTriggerResolver
→ 成功/失败
→ 成功才执行 Effect
```

例如：

```text
【冷静换道】
中盘/最终弯道被堵
→ 智慧判定
→ 成功则调整路线、降低堵塞惩罚
```

---

# 4. WisdomTriggerResolver

输入：

```text
horse.wisdom
skill.level
race_phase
race_context
horse_state
skill_trigger_definition
```

输出：

```text
activation_probability
roll
success
```

概率公式配置化。

---

# 5. 等级与智慧分工

```text
技能等级
→ 技能强度 / 部分发动修正

智慧
→ 是否稳定抓住发动时机
```

高等级不等于 100% 发动。

---

# 6. Effect Executor

统一接口：

```text
SkillEffectExecutor.execute(...)
```

支持：

```text
ModifySpeed
ModifyAcceleration
ModifyStaminaConsumption
RecoverStamina
ModifyOvertake
ReduceBlockPenalty
ChangeLanePreference
ModifyPace
TemporaryModifier
RaceModifier
```

---

# 7. Modifier

```text
modifier_id
source_skill_id
stat_or_mechanic
operation
value
start_phase
expires_phase
remaining_checkpoints
stack_policy
```

---

# 8. Stack Policy

预留：

```text
STACK
REFRESH_DURATION
KEEP_STRONGEST
REPLACE
UNIQUE
```

---

# 9. 技能发动次数

runtime：

```text
activations
last_activation_checkpoint
cooldown_remaining
```

支持：

```text
ONCE_PER_RACE
ONCE_PER_PHASE
COOLDOWN
MULTIPLE
```

---

# 10. 直播展示

发动：

```text
✨【弯道加速 Lv8】发动！

星河抓住弯道出口，突然提速！
```

智慧失败：

```text
🧠【冷静换道】未能发动。

星河犹豫了一瞬，没能及时避开前方马群。
```

只展示重要事件，避免刷屏。

---

# 11. 第一批框架验证技能

建议：

```text
被动：
强健体魄
草地巧手

条件：
疾速起步
弯道加速
末脚

智慧：
冷静换道
节奏控制
```

重点不是技能数量，而是验证框架。

---

# 13. 验收标准

- 三类技能统一注册；
- Race Engine 不知道具体技能名；
- 等级影响技能效果；
- 智慧影响智慧技能；
- Modifier 生命周期正确；
- 发动/失败可进入比赛事件流。
