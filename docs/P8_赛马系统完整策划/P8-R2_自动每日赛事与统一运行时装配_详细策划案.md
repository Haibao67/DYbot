> **阶段：P8-R2**  
> **定位：将 P8 从“规则完整 + 可模拟”推进为“每日自动运行的正式玩法”**  
> **核心目标：自动每日创建赛事、统一装配 Race Engine / Skill Registry / NPC Registry，并实现锁定、补位、快照、开赛、结算和故障恢复的完整自动化。**


# 8. Scheduler 必须幂等

以下情况：

```text
Worker重复调用

Bot重启

同一分钟调用两次

多个任务重试
```

都不能产生：

```text
重复赛事
```

依赖：

```text
数据库唯一约束
+
事务
```

保证。

---

# 9. 不依赖精准时间触发

禁止把系统设计成：

```text
12:00 必须正好执行一次

19:45 必须正好执行一次

20:00 必须正好执行一次
```

否则：

```text
Worker卡顿
服务器重启
任务延迟
```

都会造成赛事卡死。
