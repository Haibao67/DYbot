# P8-4 · Race Engine 与七阶段赛马模拟

> **目标：建立适合文字 Bot 的离散赛马引擎，让五维、相性和技能在不同阶段明确发挥。**

---

# 1. 模拟方式

禁止逐米模拟：

```text
3200m → 模拟3200次
```

采用：

```text
七阶段
+
7~10 个 Checkpoint
+
相对位置
+
状态更新
```

```text

```

---

# 6. 前段抢位

核心：

```text
速度
智慧
跑法目标位置
```

逃尝试领跑，先行进入前集团，差保持中后方，追主动留后。

因此前段排名靠后并不意味着表现差。

---

# 7. 中盘巡航

核心：

```text
耐力
智慧
距离相性
当前 pace
```

主要负责：

```text
体力消耗
节奏稳定
位置维持
```

智慧高的马更容易避免无意义高节奏消耗。

---

# 8. 弯道争夺

核心：

```text
力量
智慧
路线
超车
堵塞
```

差马与追马容易在这一阶段开始明显推进。

---

# 9. 最终弯道

开始进入决胜：

```text
力量
速度
智慧
剩余体力
技能
```

Race Engine 在此大量触发 final/corner 类技能 Hook。

---

# 10. 最后直线

核心：

```text
速度
毅力
力量
剩余体力
```

体力足够时速度完整发挥；低体力时速度上限被压低，毅力用于降低衰减。

---

# 11. 终点对抗

如果两匹马差距非常接近：

```text
head_to_head = true
```

主要比较：

```text
毅力
速度
剩余体力
相关技能
```

# 14. 体力

`stamina_max` 来源：

```text
耐力
距离相性
状态
被动技能
```

体力消耗来源：

```text
节奏
distance
running_style
track_condition
skill_effect
wisdom_efficiency
```

---

# 15. 低体力阶段

建议：

```text
>30%：正常
10~30%：轻微衰减
0~10%：明显衰减
0%：严重失速
```

毅力降低后两档的速度衰减。

---

# 16. Hook

Race Engine 必须提供：

```text
before_phase
on_phase_start
on_checkpoint
on_overtake_attempt
on_blocked
on_stamina_threshold
on_final_straight
on_head_to_head
after_phase
```

技能、未来天气事件、装备等都从 Hook 接入。

# 18. RNG

建议：

```text
±3%~5%
```

必须可注入、可固定 seed。

测试禁止 sleep。

---

# 19. 结果快照

保存：

```text
RaceResultSnapshot
```

包括：

```text
rank
horse_id
finish_gap
remaining_stamina
key_events
simulation_version
rng_seed
```

`/观赛`、`/赛果` 永远读取保存结果，不重新模拟。

---

# 20. 幂等

同一 race 只能结算一次。

即使多个 Worker 同时发现赛事到期，也必须只有一个完成：

```text
模拟
保存
发奖
解锁
```

# 22. 验收标准

- 七阶段完整；
- 五维均有明确机制；
- 相性可接入；
- 技能 Hook 可接入；
- 同 seed 可复现；
- 结果只生成一次；
- 关键事件可生成文字直播。
