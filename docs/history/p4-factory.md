# P4：持久化加工厂核心

## 最初计划

实现 T1/T2/T3 配方、流水线、升级、投产与取货。工单须保存材料、配方版本、时间、随机结果和状态；扣料、产物入库与重复取货必须原子、可恢复。P4 不包含 P5 的加急、取消和增益完整玩法。

## 实际实现

| 等级 | 配方与价格口径 | 基础工时 |
| --- | --- | --- |
| T1 | 鸡蛋 ×3→蛋糕 18；羊毛 ×2→毛衣 50；牛奶 ×2→奶酪 40，成品固定价 | 60 分钟 |
| T2（厂 Lv2 起） | 蛋糕 ×2 + 奶酪 ×1→礼盒；毛衣 ×2 + 羊毛 ×1→羽绒服；奶酪 ×2 + 鸡蛋 ×1→奶酪拼盘，基准价分别 120/160/120，随行情 | 120 分钟 |
| T3（厂 Lv4 起） | 礼盒 + 羽绒服 + 奶酪拼盘→大礼包，基准价 500，随行情 | 240 分钟 |

- 加工厂最高 Lv5，升级从当前等级 L 到下级所需货币为 `200 × 1.5^(L−1)`，不需材料。已实现逐级扩线与工时提速，Lv1 工时 ×1.0、Lv5 ×0.60；Lv2–4 每级减 10% 是为填补未给定级差的实现推导。
- 投产选择可用线并在同一事务扣材料、锁定配方和生产快照。工单状态持久化；完成后取货只发放一次，失败/暴击使用可复算的确定性结果。T1/T2/T3 暴击率分别 0%/5%/10%；配方基础失败率均为 4%，T3 在统一规则中乘 0.5，通常有效失败率为 2%（Buff 仍可改变结果）。
- 面板按真实等级、产线与工单状态生成，工单与商品接入 P3 行情/出售。早期面板直接列配方；后续本地修订改为 `/加工厂` 仅展示产线和状态，完整配方通过 `/配方` 查看。该本地修订截至整理日尚未部署。
