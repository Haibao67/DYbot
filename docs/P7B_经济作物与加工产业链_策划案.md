# 🌾 DYbot · P7B「经济作物与加工产业链」策划案

> **阶段：P7B**  
> **主题：经济作物 × 加工厂扩展 × 动态行情 × 农业产业链**  
> **定位：在 P7 农场基础上加入专门用于赚钱与加工的经济作物，让农场从“马粮资源系统”扩展为与牧场并列的核心生产产业。**

---

# 0. 一页看懂 P7B

P7B 新增 4 种经济作物：

```text
🌾 小麦
🌻 向日葵
🍇 葡萄
🧵 棉花
```

核心流程：

```text
购买种子
  ↓
播种
  ↓
收获经济作物
  ↓
选择：直接出售 / 送入加工厂
  ↓
T1 加工品
  ↓
继续制作 T2 高级加工品
  ↓
根据 /行情 决定出售时机
```

一句话概括：

> **马粮作物服务马厩，经济作物服务赚钱与加工。**

# 1. 系统定位

P7 原有农场主要生产：

```text
🌿 牧草
🌾 燕麦
🥕 胡萝卜
🌾 大麦
🌱 苜蓿
🍎 苹果
```

主要进入：

```text
农场 → 配制马粮 → P6 马厩培养 / 繁育
```

P7B 增加：

```text
农场 → 经济作物 → 加工厂 → 高级商品 → 动态行情 → 玩家经济
```

于是铃露拥有两条并列基础产业：

```text
🏡 牧场
动物资源 → 鸡蛋 / 羊毛 / 牛奶 → 加工厂

🌱 农场
植物资源 → 小麦 / 向日葵 / 葡萄 / 棉花 → 加工厂
```

# 4. 天气联动

继续复用 P2 / P7 天气系统：

- ☀️ 晴天：所有作物生长速度 +10%
- 🌧️ 雨季：牧草 / 苜蓿产量 +20%；棉花产量 -10%
- 🏜️ 旱季：小麦产量 +10%；牧草 / 苜蓿产量 -20%
- 🥵 闷热：葡萄产量 +10%；苹果产量 -10%
- 🍃 微风：无影响
- 🎊 丰收祭：所有作物产量 ×1.30

天气效果继续使用“播种快照”，不在作物生长途中重算。

## 价格实现规则

1. 种子使用固定商店价格，不进入动态行情。
2. 经济作物的表内价格是 `base_price`，实际成交价走 P3 市场窗口。
3. T1 / T2 加工品的表内价格同样是 `base_price`，实际成交价走动态行情。
4. 加工不保证永远比直接出售原料更赚钱。
5. 未来 T3 在正式开放前必须单独确认基准价格。

# 10. 经营决策

P7B 不希望玩家形成：

```text
只要加工就一定赚钱
```

而应该形成：

```text
现在直接卖？
还是做 T1？
还是继续做 T2？
```

例如：

```text
🌾 小麦行情高
🍞 面包行情低
```

此时直接卖小麦可能更划算。

反之：

```text
🌾 小麦低迷
🍞 面包上涨
```

则适合加工。
