# P8-R1 implementation

## 2026-09-28 — Slice 1: affinity and frozen numerical contracts

依据 `P8-R1_真实比赛规则V1_详细策划案.md`，本轮按 AGENTS.md 的“一轮一个可验收垂直切片”实施相性生成 → 亲本补定 → 繁育快照 → 接生落库，并保存下一切片使用的完整基础公式。未部署。

### Implemented

- G0 距离/跑法 2/10/28/40/20，场地 2/12/36/35/15；相性独立于成长和五维。
- 各类全部低于 B 时随机挑一槽，使用策划的独立保底概率：距离/跑法 1/13/86；场地 1/17/82。不再按原始概率条件抽取保底。
- 完整十五种无序亲本组合遗传表，父母顺序对分布无影响。
- 每槽独立变异：+2 0.5%、+1 4.5%、不变90%、-1 4.5%、-2 0.5%，边界限制在 D～S；后代无 B 保底。
- 快照保存基础抽样、基础结果、变异抽样/级差、最终结果及独立算法/seed 引用。繁育时冻结，接生时幂等应用。
- 新购买 G0 立即补定相性；旧马在 `/马` 或作为繁育亲本时补定。`/马厩`不批量补定旧相性，已补定记录不重抽。
- 既有怀孕记录缺 P8 相性快照时继续保持 U，避免用当前亲本和新规则伪造历史遗传。
- `domain/race_rules_r1.py` 保存距离/场地/跑法分机制倍率、赛道倍率、四跑法阶段表、体力/几何阈值、九 checkpoint、固定赛事与30技能ID。
- Decimal 实现基础速度、加速度、最大体力、赛事消耗、智慧节能、疲劳/毅力保护、分段加速时间、智慧发动概率。属性超出 0～1000 时明确拒绝，不偷偷修改玩家资产。

### Not enabled in this slice

真实比赛、每日赛事自动创建、30技能执行配置、G0/旧马六技能自动补定、NPC正式模板和比赛引擎 V1。

原引擎以固定 elapsed 更新距离；R1要求按 segment distance 计算各马完成时间，不能只把新系数装到旧引擎便报告真实比赛可用。

R1照片判定要求 finish_time 到0.001秒，再 DuelScore → horse_id，取代早期框架的 seed平局顺序；将在真实引擎切片处理。

R1允许锁定后继续培养是可选项，本轮保留既有更严格资产锁，避免未完成引擎/快照验收时改变跨系统行为。

- 超车公式中的 SpeedAdvantage、RunningStyleBonus、LaneBonus、TrackPenalty。

- 每日12/19:45/20点后续沿用项目的北京时间口径；正式赛程还未创建。
